# NNNN. Short title in the imperative

- **Status:** Proposed | Accepted | Superseded by NNNN
- **Date:** YYYY-MM-DD

## Context

What forced a decision here? State the constraint, not the feature. If you
cannot name a constraint, you probably do not need an ADR.

## Options considered

### Option A — name

How it works, in two or three sentences. Then what it costs.

### Option B — name

Same. Include at least one option you seriously considered and rejected. An
ADR with a single option is a note, not a decision.

## Decision

What you chose, stated plainly.

## Rationale

Why this option beat the others *given the constraints in Context*. The
honest version usually mentions something you gave up.

## Consequences

What is now harder, what is now easier, and what you will have to revisit if
a stated assumption changes. Name the assumption explicitly.
